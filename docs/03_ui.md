## 基本的な画面の動き
### ログイン

### ダッシュボード：
- 情報
```
ボタン
├─ログイン：
├─シナリオ一覧：
├─シナリオ新規作成：
├─シナリオ施行：
└─結果一覧：
```
### ■ログイン：
- ユーザーID、パスワードの入力
- Googleとの連携でも可能

### ■シナリオ一覧
- 登録済みのシナリオが確認できる。
- コピーしての作成も可能
```
ボタン
├─新規：
└─テーブル各行
      ├─確認
      ├─コピー作成：
      └─レポート一覧
```

### ■シナリオ新規作成
- 新規でシナリオを作成する
- 名前、説明を入力する
- 一覧からの遷移時には一覧の元のデータが遷移する
```
入力
├─名前
├─説明
└─条件
ボタン
└─登録：
```



### シナリオ施行
- 選択されたシナリオに基づいて、再生していく
- ターンｘｘｘ中ｘｘｘのように進捗が見えるように
- 他に、アクターの状況が見えるようにする
- ターン0/100は開始位置、ターン１で行予定の内容を提示する。
- ターン1/100は1回施行した後、ターン２で施行する内容を提示する
- ターン2/100は2回目施行した後、ターン３での施行する内容を提示する
- ターン100/100は100回施行した状態。次へボタンをは押下できない。

```
ボタン
└｜先頭へ｜前へ（１０）｜前へ（１）｜次へ（１）｜次へ（１０）｜最後へ｜
```

### 結果一覧
一覧から結果を選んで詳細確認
シナリオ施行へも遷移可能

### 主画面のレイアウトポイント

* **左カラム（設定パネル）**: シミュレーション中であってもパラメータ変更・制度介入が可能（htmx経由でバックエンド/ブラウザエンジンへ即時反映）。
* **中央メイン（可視化キャンバス）**: 資産分布（ヒストグラム）、地域グループ間の取引（ネットワークマップ）、ローレンツ曲線をタブで切替表示。再生スピードスライダーや1コマ送りボタンを配置。
* **右カラム（KPI・ログ）**: ジニ係数のリアルタイム変動や各階層の資産シェア、シード値による再現・リプレイ実行用操作ボタンを配置。

### 分析画面のレイアウトポイント

* **エグゼクティブ・サマリー**: シミュレーションの結論（格差の拡大度合いや制度による抑止効果の数値）を上部にカード形式で集約。
* **インタラクティブチャート**: Plotly等を用いたズーム可能な時系列グラフ。「どのターンで政策介入が行われたか」の注釈ピン（📌）を表示。
* **個別エージェントマトリクス**: 最終ターンにおける全エージェントのソート・検索可能なデータテーブルを表示し、分析結果（CSV/PDF）のエクスポートボタンを配置。
