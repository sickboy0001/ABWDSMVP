## 基本的な画面の動き
### ログイン

### ダッシュボード：
- 情報
```
ボタン
├─ログイン：
├─シナリオ一覧：
├─シナリオ新規作成：
├─シナリオ施行：
└─結果一覧：
```
### ■ログイン：
- ユーザーID、パスワードの入力
- Googleとの連携でも可能

### ■シナリオ一覧
- 登録済みのシナリオが確認できる。
- コピーしての作成も可能
```
ボタン
├─新規：
└─テーブル各行
      ├─確認
      ├─コピー作成：
      └─レポート一覧
```
      
### ■シナリオ新規作成
新規でしなりを作成する
名前、説明を入力する
一覧からの遷移時には一覧の元のデータが遷移する
入力
├─名前
├─説明
└─条件
ボタン
└─登録：



### シナリオ施行
選択されたシナリオに基づいて、再生していく
ターンｘｘｘ中ｘｘｘのように進捗が見えるように
他に、アクターの状況が見えるようにする
ターン0/100は開始位置、ターン１で行予定の内容を提示する。
ターン1/100は1回施行した後、ターン２で施行する内容を提示する
ターン2/100は2回目施行した後、ターン３での施行する内容を提示する
ターン100/100は100回施行した状態。次へボタンをは押下できない。

ボタン
└｜先頭へ｜前へ（１０）｜前へ（１）｜次へ（１）｜次へ（１０）｜最後へ｜

### 結果一覧
一覧から結果を選んで詳細確認
シナリオ施行へも遷移可能



## 条件
- ルール設定群　エージェント数、初期資産、初期資産比率、ターン数、税率、UBI、強者優遇ルール等

### 基本設定
- ターン数
- エージェント数
- 初期資産（基本）

### 初期資産
- 公平な資産
- 不公平な資産
  - トップ１０％は所持金＋１０％　トップ１０％は所持金ー１０％
    - トップX％は所持金＋Y％　トップX％は所持金ーY％
### 行動選択設定
- ゼロサム戦闘
- 待機率（Def0%）
  - 戦闘参加率
- 投資家型行動（Def0％）資産を+5%（N％）増やす
- 学習エージェント（動的状態遷移）勝敗履歴（例: 3連勝/3連敗）に応じて、性格（保守型 / 積極型 / 超積極型）や行動方針が動的に変化する機能。

### ゼロサム戦闘・基本
- ランダムマッチ
- 強者優遇（Top10%の人は勝率が10%上がる）TopN％の人、勝率M％アップ

### ゼロサム戦闘・掛金
- 弱者所持率100%(Def)
- 各々の所持金の100%

### 再分配
- **弱者救済**: 上位層から下位層へ毎ターン一定額の資産を移譲する機能。
  - 一定額(基本所持の10%など)
  - 比率（所持の10%など）
- **基本所得 (UBI)**: 全エージェントへ毎ターン一定額を支給する機能。
  - 一定額(基本所持の5%など)
  - 比率（所持の5%など）

### 社会制度
- **累進課税**: 設定した閾値以上の資産を持つエージェントから指定率で徴税する機能。
  - 閾値（初期値の200%）徴収額（初期値の10%)
- **貧困脱落**: 所持金が指定閾値未満となったエージェントをシミュレーションから強制退場（脱落）させる機能。
  - 閾値（初期値の10%）
  - 各エージェント合計の1%など
- **インフレ設定**: 毎ターン全エージェントの所持金を一定割合で目減りさせる機能。
  - 一定額（初期値の３％など）
  - 各エージェント合計の1%など
  - エージェント毎所持金額の３％など

### 環境・情報

- **コネ社会（地域限定マッチング）**: 全体ランダム対戦を無効化し、指定グループ（地域等）内でのみマッチングを制限する機能。
  - グループ数、比率を指定
    - グループ数：４　メンバー数 ２：２：１：１など 
* **情報格差**: 特定条件（例: 上位層）のエージェントのみが対戦相手の正確な資産残高を確認できる機能。
