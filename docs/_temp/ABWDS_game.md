# エージェントベース経済シミュレーション
Agent-Based Wealth Dynamics Simulator-> ABWDS

## 目的
現実的なシナリオを想定し、そのうえで適切な戦略を考えたいと思っています。
現実的なシナリオを想定してるため、以下をすべて仕組み化して、
各引数を個別に登録できるように（参加者数）、不公平な資産での金額の差異
挑まない場合の率（以下の例なら２０％ゲーム回避）
「ABWDS-強者優遇」の具体的な率
「弱者救済」の具体的な率、金額
「累進課税」の具体的な金額、納税額
などを想定しています。

## ABWDS-強者優遇
10000円未満 勝率50%
10000円以上 勝率55%
20000円以上 勝率60%
50000円以上 勝率70%
50%以上の場合は対戦相手の勝率と、当事者の勝率を比較して、勝率を調整する


## ABWDS-弱者救済
上位１０％が下位１０％に毎ターン
５００円を移譲
上位から下位へ

## ABWDS-資産比例賭博
資産の10%を取り合う
A-資産10000、B-資産5000
10%取り合うので
A勝利 A資産10500 B資産4500
B勝利 A資産9000 B資産6000
目的：大金持ちの変動幅を観察。
